# AntiCorrupcion Ciudadana

## Sigue el dinero público y detecta irregularidades en cualquier país

**Autor: Josué Israel Cervantes Alavarado**

Es un proyecto de mapeo e investigacion forense de alto nivel la intencion es auditar a todo servidor publico a nivel internacional y recabar información o datos sobre corrupción, empresas fantasma, desvios economicos o simulaciones/inflaciones en costos de obra. Si la autoridad nos vigila nuestro deber es vigilarla.
